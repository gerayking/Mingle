群聊旁听 V2：要改的地方

RFC 0001 的界面原型。控制台只改群展开后顶部的"听群里所有的话"那一块：多一个"回得多快"三档、一行现在的状态、一行"群里怎么叫它"。聊天软件里没有新界面，变化是回得更早、先说一句。官网在发布后换一段文案、补两张图。

1. 控制台：群里"听群里所有的话"那一块

  • 三档是一个分段控件，选项只写"省 / 均衡 / 快"。下面一句说清选中那档的代价，数字只写"每小时最多多用约 N 轮"，不显示令牌、E 这类内部词。默认按群的人数选，说明里写"默认用这一档"；owner 选过之后这句话就不出现了。
  • 状态行只有三种，都用文字，不用颜色区分含义：正在和某人聊（绿点）/ 在旁听 / 慢下来了。"慢下来了"和 Agent 自己设的 --every / --mute 沿用现在的文案和"恢复默认"。多个人同时在聊时写"正在和李雷、韩梅梅聊"，超过两个人写"正在和 3 个人聊"。
  • 群里怎么叫它：第一项是 Agent 的名字，不能删。owner 原地添加或删除称呼（回车添加，Esc 取消），Agent 用 chat alias 加的也列在这里，后加的覆盖不了先删的。最多 8 个，每个最长 16 个字。
  • 关掉"听所有"时，三档、称呼和状态行都收起来，和现在一样只剩开关和一句"只有 @ Alex 或回复它时，它才回应"。私聊和话题不显示这一块。

2. 聊天软件里：没有新界面，只是回得更早

同一段对话，左边是现在，右边是 V2。机制上的变化：在聊的人说完就交，不等 2 分钟间隔；提示语让它先回一句再动手、一条一个意思；对方在补充自己的话时，插进正在跑的那一轮。

3. 官网：发布后改一段文案、补两张图

只动"一个 Agent"那一节的一个要点和"和它说话"那一步，不新开版块。截图在发版后用 site/scripts/screenshots.mjs 和 demo.mjs 重拍，中英文、明暗各一套。

"一个 Agent"里的要点

听得见群里在聊什么

群里的对话它当作背景留着，回答前先补看错过的消息。

跟得上群聊

不用每句都 @ 它。有人和它聊起来，对方说完它就接话，先回一句再去办；和它无关的闲聊，它只是听着，也不乱花额度。

"和它说话"那一步

私聊它，或在群里 @ 它、叫它的名字。它一开始处理就会回应，回复边做边更新……
